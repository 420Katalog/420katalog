# 420Katalog Website

**Slogan:** “Euphoric Lifestyle”

Responsive static website for 420Katalog, built with HTML, CSS, and vanilla JavaScript. Ready for free hosting with GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and automatic copyright year
- `.github/workflows/pages.yml` — automatic GitHub Pages deployment on pushes to `main`

## Publish on GitHub Pages
1. Create a new repository on GitHub, such as `420katalog`.
2. Upload the contents of this package to the **root** of that repository. Make sure `index.html` is at the root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**. If prompted, select **GitHub Actions** as the deployment source.
5. Open **Actions** and wait for `Deploy 420Katalog to GitHub Pages` to finish successfully.
6. Find the live URL under **Settings → Pages**. It usually looks like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

If the repository is named `YOUR-USERNAME.github.io`, the URL is usually `https://YOUR-USERNAME.github.io/`.

## Updating the site
Edit the files and push changes to `main`; the included workflow will publish the update automatically.

## Before launch
- Confirm the YouTube channel link is correct.
- Add real product/store links and a contact destination if you want to support purchases or direct enquiries.
- Test the published site on mobile and desktop.
